# 🍕 Pizza Miami — Next.js Website

A full-featured fast food ordering website for **Pizza Miami**, Liverpool.

## Features
- Full menu from both menu cards (excluding Cheesess Platter)
- Category-based browsing with 15 categories
- Add to cart with quantity management
- Cash-on-delivery checkout with form validation
- Responsive — mobile-first design
- Open 3pm–3am info, contact details, address
- 20% cheaper than Just Eat banner
- Smooth animations and modern dark design

## Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm start
```

## Customisation

- **Menu items**: Edit `src/lib/menu-data.ts`
- **Phone number**: Search for `01512601770` and replace
- **Address**: Search for `Townsend Lane` and replace
- **Opening hours**: Edit in `Hero.tsx`, `AboutSection.tsx`, `Footer.tsx`
- **Colours**: Edit CSS variables in `globals.css`

## Tech Stack
- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Lucide React** (icons)
- Google Fonts: Bebas Neue, Syne, DM Sans
